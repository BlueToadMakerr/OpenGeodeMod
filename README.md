# OpenGeode
Welcome to OpenGeode! A mod that allows you to use other indexes, or browse things you aren't supposed to access normally on the Geode Index.

Here are the indexes that come bundles with this mod
## Pre Installed Indexes
* **Geode Index API** - This is the default Geode Index. This is where you can access mods approved by the index team
* **Open Geode Index** - This is a very popular alternative to the Geode Index. This is a place where you can upload any mod you want, without it having to be manually verified and where some people publish their mods when it gets rejected.
* **Rejected Index** - This is where all rejected mods go. Every almost rejected mod gets put into this index (as Geode normally required Admin auth to access) and saved for you to download from

## How to install
1. Download the latest version of this mod in the Releases tab
2. Open Geometry Dash and go into Geode. Click the settings button at the bottom left
3. Click `Install From File`. A warning will pop-up saying that installing mods outside GD is dangorours. Skip it and select the file you downloaded and confirm.
4. Restart Geometry Dash. You should now see a blue Geode logo to the left. This is where you manage and switch your indexes.

## Features!
This mod also adds a bunch of QOL features to give you more access to the Geode Index.
* **Login** - Next to the back button is a profile button. Use that to log into the index and manage your mods, and submitting new ones. This is also used to use anything that requires verification.
* **Filters** - Next to the sort button will be a Geode button that allows you to view unlisted, rejected, and pending mods. You can also change what your device reports in the perams section.
> [!Note]
> Rejected might need authentication to access
* **Versions** - You can download any version of a mod you want, not just the latest one, in the Verions pop-up next to the Install button
* **Comments** - Geode has comments mainly used for internal discussion for mods. You can now see these comments, and comment yourself (with auth) in the comments tab
* **Update Manager** - This simply allows you to update from multiple indexes on one screen. Useful so you don't need to switch indexes to see which index has updates for which mod.

## Server Hosting!
To host your own Geode server, you can use [OpenGeode](https://github.com/BlueToadMakerr/OpenGeode) or [Geode Server](https://github.com/geode-sdk/server). OpenGeode is more compatible with the OpenGeode mod but Geode Server is more up to date.
